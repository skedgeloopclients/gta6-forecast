Hour-by-hour GTA VI Twitch viewer forecast from hour 1's print. The model learns each past launch's
release-day log viewer curve relative to its own hour 1, weights big console launches more heavily,
and blends the comparable shape with persistence before emitting five quantiles per hour. Standard
library only, offline, deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
